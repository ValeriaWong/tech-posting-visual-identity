# 技术帖主视觉设定仓库

技术社区发帖（ModelScope / 掘金 / CSDN / InfoQ 那套文章）的固定主视觉。所有文章配图都按这里来。

- 版本：v1.0，2026-11-25，Allen 定深夜台灯风
- 设定文档：`主视觉设定.md`（唯一规范正文）
- 样式变量：`tokens.css`（新图直接引用）
- 例子：`examples/`（串聊文章的 9 张图，`-lamp-v2` 版）
- 渲染脚本：`scripts/`（`fig_common.py` 是共享色板，9 个 `render_*.py` 各出一张图）

## 方向

深夜台灯风，来源是 P0 法律自媒体旁聊的三个方向里的 C（AGENTS.md 封面 v3 的路子）：深青黑底、衬线白字、一点暖黄灯光。法律号最后选了 B（AI 抽象插画风），C 留作备选；技术帖这边用 C。第一版凭感觉做的蓝炭底 + 无衬线 + 琥珀泛滥是错的，已废弃。

## 怎么出新图

1. 在 `scripts/fig_common.py` 里取色，不要自己现配。
2. `python3 scripts/render_<名字>.py` 就能重画一张。注意：脚本里的保存路径目前指向 `~/workspace/modelscope-drafts/images/`（稿子引用的地方），仓库里的 `examples/` 是快照副本，出新版后记得一起更新。
3. 改版必须换新文件名（`-lamp-v2` → `-lamp-v3`……），同名覆盖 Allen 那边缓存看不到。
4. 只改样式，不改数字和文字；数据变了要先核对出处再改。
