# 技术帖主视觉设定仓库

技术社区发帖（ModelScope / 掘金 / CSDN / InfoQ 那套文章）的固定主视觉。所有文章配图都按这里来。

- 版本：v2.0，2026-11-25，WorkBuddy 视觉设计师专家规范，经 Allen 定：单色极简，冷灰白底、白卡、一个科技蓝是唯一高亮色
- 设定文档：`主视觉设定.md`（唯一规范正文）
- 样式变量：`tokens.css`（新图直接引用）
- 例子：`examples/`（串聊文章的 9 张图，`-mono-v1` 版）
- 渲染脚本：`scripts/`（`fig_common.py` 是共享色板，9 个 `render_*.py` 各出一张图）

## 方向

单色极简：画布底 `#F7F8FA`（冷灰白）、卡片 `#FFFFFF`、科技蓝 `#2563EB` 是唯一高亮色，零红、零琥珀、零暖色、零深色背景、零光晕。蓝只允许出现在 5 个位置（标题下划线、关键卡描边、新做法柱、测过状态、强调数字），每图蓝色像素 ≤5%（柱状图 ≤8%）。

v1.x 深夜台灯风（深青黑底、衬线白字、一点暖黄灯光）已全部作废：v1.0 初版凭感觉做的蓝炭底 + 无衬线 + 琥珀泛滥是错的；v1.1 专家修太暗版因为 Allen 说暗红色太蠢，整个深底方向不要了；v1.2 极简白底版色值偏暖偏淡，也被 v2.0 全部重定。深夜台灯风只留作历史记录，不再是任何方向的规范。

## 怎么出新图

1. 在 `scripts/fig_common.py` 里取色，不要自己现配。
2. `python3 scripts/render_<名字>.py` 就能重画一张。注意：脚本里的保存路径目前指向 `~/workspace/modelscope-drafts/images/`（稿子引用的地方），仓库里的 `examples/` 是快照副本，出新版后记得一起更新。
3. 改版必须换新文件名（`-mono-v1` → `-mono-v2`……），同名覆盖 Allen 那边缓存看不到。
4. 只改样式，不改数字和文字；数据变了要先核对出处再改。
